## 二、Windows 平台支持（e9adb73）

代码已加入 Windows x64 支持（sqlite-vec 平台加载 `windows-x64/vec0.dll`、Python 探测常见安装位置与 PATH、终端 PowerShell/CMD/Git Bash/WSL、`build:win` 打包链与 NSIS/portable 目标），但所有文档仍只描述 macOS。本次同步：

- README.md / README.en.md：标题、平台徽章（`macOS_arm64 · Windows_x64`）、平台说明、源码启动准备、构建段落（新增 `pnpm run build:win` 与产物名 `Trellora-<version>-setup-x64.exe` / `-portable-x64.exe`）。
- docs/architecture.md / .en.md：整体架构声明改为"主要目标 macOS arm64，已添加 Windows x64 支持"。
- docs/Trellora-2.0-产品说明文档.md：平台与运行条件、事实来源中的打包配置描述。
- AGENTS.md：工程约束中的平台断言与验收环境（保持原约束语义，仅同步平台事实）。
- 下载版本号仍为 v1.2.0（已核实 Gitee Releases 仅有 v1.0.0/v1.1.0/v1.2.0，v1.2.3 无 release 页，仅代码 tag）；未虚构 Windows 发布下载，Windows 仅描述为"可从源码构建"。
